# Glosario de estados

Qué significa cada estado, qué permite y qué bloquea. El portal escribe siempre el valor de la API (`SUSPENDED`) y su etiqueta en español («Suspendida»). La etiqueta es **por entidad**: `UNVERIFIED` es «No verificada» para una empresa y «No verificado» para la cobertura de SIGERSOL.

- [Estados de auth-service](estados-auth.md): cuentas del personal, roles, y el código y el token de la recuperación.
- [Estados de recycler-service](estados-recycler.md): asociaciones, recicladores y certificaciones.
- [Estados de collection-service](estados-collection.md): vecinos, cronogramas y recojos.
- [Estados de reporting-service](estados-reporting.md): empresas, certificados, orígenes del dato SIGERSOL y contexto distrital.
